# marcinmoskala.com / marcinmoskala.pl

Personal site of Marcin Moskała. Static HTML generated by a dependency-free Node script.

- Content: `src/content.mjs` (projects, bio, books, conf page talks; text as `t(en, pl)`),
  `src/talks.json` (all talks), `src/strings.mjs` (UI text per language).
- Build: `node build.mjs` writes the English site to the repository root (served by
  GitHub Pages at marcinmoskala.com) and the Polish site to `_pl/`.
- Publish English: commit the build output and push to `master`.
- Publish Polish: `scripts/publish-pl.sh` copies `_pl/` to the repo behind marcinmoskala.pl.

Generated files (do not edit by hand): `index.html`, `projects/`, `talks/`, `conf/`, `404.html`,
`sitemap.xml`, `robots.txt`, `_pl/`, and the redirect pages `conf.html`, `skills.html`,
`delegates/`, `blog/`, `blog-pl/`.
